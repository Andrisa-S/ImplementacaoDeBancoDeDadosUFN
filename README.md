# 🗄️ Implementação de Banco de Dados — UFN

Repositório com exercícios e conceitos desenvolvidos durante a disciplina de Implementação de Banco de Dados do curso de Ciência da Computação na **Universidade Franciscana (UFN)**, utilizando **T-SQL**.

O repositório é organizado por tema, cobrindo desde a automação de comportamentos no banco (bancos de dados ativos) até o controle de acesso e o versionamento de dados ao longo do tempo.

---

## 📁 Temas do repositório

### ⚡ Banco de Dados Ativos
Estudo de **triggers** (gatilhos), que executam ações automaticamente em resposta a eventos no banco:

- **Triggers AFTER**: executadas após a operação ser realizada
- **Triggers INSTEAD OF**: substituem a operação original por uma lógica customizada
- Eventos cobertos: `INSERT`, `UPDATE` e `DELETE`

Também aborda **Views**: consultas armazenadas que funcionam como tabelas variáveis, simplificando o acesso a dados complexos ou combinados.

### 🔐 Gerenciamento de Usuário
Controle de permissões e acesso ao banco de dados:

- **GRANT**: concessão de permissões
- **DENY**: negação explícita de permissões
- **REVOKE**: revogação de permissões previamente concedidas

### 🕒 Banco de Dados Temporais
Modelagem de dados que preservam o histórico de alterações, permitindo consultar o estado das informações em diferentes pontos no tempo.
